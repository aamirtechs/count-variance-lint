How it works

  • Two CSVs (system and counted), or one combined CSV with both quantity columns.
  • Matching on a composite SKU + location key, with explicit duplicate-key warnings instead of silent overwrites.
  • Variance units, percent and value per line, ranked by absolute value impact so shrinkage surfaces first.
  • Threshold flags mark lines that need investigation.
  • Download a recount sheet for the top N lines and the full variance report as CSV.
